# 🌱 Plant Health Detector (Supervised ML Project)

This project is a web-based application that uses a **Supervised Machine Learning model** to classify plant images as **Healthy** or **Unhealthy**.

The model is trained using Google's Teachable Machine and deployed in the browser using TensorFlow.js.

---

## 🧠 Machine Learning Approach

- **Type:** Supervised Learning  
- **Model:** Image Classification  
- **Training Tool:** Google Teachable Machine  
- **Input:** Plant leaf images  
- **Output:** Class label (Healthy / Unhealthy) with probability scores  

The model learns from labeled training data and predicts the class of new unseen images.

---

## 🚀 Features

- 📁 Upload / Drag & Drop plant images  
- 🤖 Real-time prediction in browser  
- 📊 Confidence score display  
- 🌿 Health classification (Healthy / Unhealthy)  
- 💡 Basic plant care suggestions  
- 🔄 Reset functionality  

---

## 🛠️ Tech Stack

- HTML, CSS, JavaScript  
- TensorFlow.js  
- Teachable Machine (for model training)  

---

## 🔍 How It Works

1. User uploads a plant image  
2. Image is passed to the trained ML model  
3. Model processes the image using learned patterns  
4. Outputs prediction with probability  
5. UI displays result + suggestions  

---

## 📊 Example Output

- Healthy → High confidence → Maintenance tips  
- Unhealthy → Detection → Care suggestions
